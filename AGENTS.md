# AGENTS.md

## Projeto

Rezenhaí é um MVP web em Next.js + TypeScript + Tailwind para criação e compartilhamento de convites digitais informais no Brasil.

## Escopo obrigatório do MVP

- Marketing site com proposta de valor, como funciona, exemplos e recursos.
- Fluxo web de criação de convite para host.
- Página pública do convite com confirmação de presença pelo navegador.
- Dashboard simples do host com presença, checklist, Pix manual assistido e fotos.
- Tudo em PT-BR, tom informal, direto e quente.

## Fora de escopo

Não adicionar monetização, planos pagos, Explore/mapa de eventos, Pix automático, split automático, marketplace, delivery, WhatsApp oficial automático, app nativo, capa por IA como recurso ativo, replay de fotos com música, chat interno ou feed social.

## Design system

Use `rezenha-design-system/project` apenas como referência visual e técnica. Não altere o ZIP, não extraia o ZIP, não remova assets do handoff e não adicione binários novos ao PR.

## Estilo de UI

- Sentence case em títulos, botões e labels.
- Usar “você”, “convite”, “galera”, “Quem chamou” e “organiza”.
- Não usar “RSVP”, “Event”, “Host”, “Guests”, “Going/Maybe/No”.
- Emoji só onde tem festa: confirmação, capas/templates e chips de categoria.
- Interface limpa com uma fonte principal de cor/expressão por tela.
