# Roadmap

## Agora — MVP web

- Landing page responsiva.
- Fluxo de criação de convite.
- Página pública do convite.
- Dashboard do host.
- Estados visuais de confirmação, Pix manual, checklist e fotos.

## Próximo — MVP funcional

- Persistência de convites.
- Slugs públicos por convite.
- Confirmações reais por convidado.
- Upload de fotos com controle de participantes.
- Compartilhamento manual mais polido para WhatsApp.

## Depois — Organização do rolê

- Edição pós-publicação.
- Lembretes manuais e calendário.
- Permissões simples para quem chamou.
- Melhorias de acessibilidade e estados vazios.

## Não priorizar antes de validação

- Monetização.
- Pix automático ou split.
- Explore/mapa.
- App nativo.
- Marketplace/delivery.
- Feed social ou chat interno.
