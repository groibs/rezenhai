- Brand assets: `assets/` (Laje logo + Creme/branco logo + favicons)
- UI references: `ui_kits/web/index.html`, `ui_kits/mobile/index.html`
- Preview cards (Type / Colors / Spacing / Components / Brand): `preview/`

## Sacred rules
- **Never** use the word "RSVP" in UI — always "Confirmação de presença"; "Você vai colar?" on the guest screen.
- **Never** use "Campos rápidos" — always "Adicionar ao convite".
- **Six pillars**: Laje · Creme · Prata · Brasa · Lima · Holo. Rule-of-one accent per screen.
- **Holo is a material**, not a flat color — gradient pink→lilac→cyan→mint→peach. Text on Holo is always Laje 950.
- **Sentence case** in all UI. No periods on buttons or titles.
- No Brazilian flag, no carnaval caricature, no SaaS-frio, no Partiful clone.
