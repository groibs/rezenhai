# Rezenhaí — UI Kit Mobile

Sete telas-chave do fluxo mobile, lado a lado:

1. **Página pública** com confirmação inline — capa, info, "Você vai colar?" + 3 botões na mesma tela. Não existe tela separada só pra RSVP; o convidado responde direto aqui e o fluxo continua na captura de nome.
2. **Captura de nome** — passo 1 do fluxo do convidado
3. **Pix da resenha** — passo 2, copia chave + "Já paguei". Microcopy: "O Pix vai direto para o organizador do evento. O Rezenhaí só ajuda a organizar."
4. **Quer levar algo?** — passo 3, checklist
5. **Fechou. Você está na lista.** — passo 4, confirmação final
6. **Dashboard mobile** do host
7. **Fotos da resenha** — álbum simples

Todas usam o sistema definido em `../../colors_and_type.css`.
